# Todoist

## From any app
- `Win+Alt+Q` Quick add
- `Win+Alt+S` Show or hide Todoist

## Tasks
- `Q` Quick add
- `A` Add a task at the bottom
- `Shift+A` Add a task at the top
- `S` Add a section
- `E` Complete the selected task
- `T` Set due date
- `Y` Set priority
- `Ctrl+→ / ←` Indent / outdent
- `Ctrl+Enter` Save the task

## Go to
- `G I` Inbox
- `G T` Today
- `G U` Upcoming
- `/` Search
- `M` Toggle sidebar
- `?` Show all shortcuts

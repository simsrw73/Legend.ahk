# Typora

## Write
- `Ctrl+1–6` Heading 1–6
- `Ctrl+0` Paragraph
- `Ctrl+=` Raise heading level
- `Ctrl+-` Lower heading level
- `Ctrl+Shift+K` Code fence
- `Ctrl+Shift+M` Math block
- `Ctrl+Shift+Q` Quote
- `Ctrl+Shift+[` Numbered list
- `Ctrl+Shift+]` Bulleted list
- `Ctrl+T` Insert table
- ``Ctrl+Shift+` `` Inline code
- `Alt+Shift+5` Strikethrough
- `Ctrl+K` Link
- `Ctrl+Shift+I` Image
- `Ctrl+\` Clear formatting
- `Ctrl+Shift+V` Paste as plain text
- `Ctrl+Shift+C` Copy as Markdown

## View
- `Ctrl+P` Open quickly
- `Ctrl+/` Source code mode
- `Ctrl+Shift+L` Toggle sidebar
- `Ctrl+Shift+1` Outline
- `Ctrl+Shift+2` Articles
- `Ctrl+Shift+3` File tree
- `F8` Focus mode
- `F9` Typewriter mode
- `Ctrl+Tab` Next document

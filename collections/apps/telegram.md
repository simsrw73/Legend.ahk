# Telegram

## Chats
- `Ctrl+K` Quick search (Ctrl+F in a chat)
- `Alt+↑ / ↓` Previous / next chat
- `Ctrl+Shift+↑ / ↓` Previous / next folder
- `Ctrl+0` Saved messages
- `Ctrl+J` Contacts
- `Ctrl+L` Lock Telegram

## Messages
- `↑` Edit your last message
- `Ctrl+↑ / ↓` Pick a message to reply to
- `Ctrl+O` Send a file
- `Ctrl+Shift+X` Strikethrough
- `Ctrl+Shift+M` Monospace
- `Ctrl+Shift+N` Clear formatting

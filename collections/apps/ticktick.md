# TickTick

## From any app
- `Ctrl+Shift+A` Quick add
- `Ctrl+Shift+L` Mini window
- `Ctrl+Shift+P` Start or stop a pomodoro

## Tasks
- `Ctrl+N` Add task
- `Ctrl+Shift+M` Complete task
- `Ctrl+D` Set date
- `Ctrl+1` Due today
- `Ctrl+2` Due tomorrow
- `Ctrl+3` Due next week
- `Ctrl+S` Sync

## Go to
- `Ctrl+Alt+1` Inbox
- `Ctrl+Alt+C` Calendar
- `Ctrl+Alt+A` All tasks
- `Ctrl+/` Show all shortcuts

# Everything

## Search
- `Ctrl+N` New search window
- `Alt+↑ / ↓` Search history
- `Ctrl+1–9` Sort by name, path, size, extension, type, modified…
- `Ctrl+P` Options

## Results
- `Ctrl+Enter` Open the containing folder
- `Alt+Enter` Properties
- `F2` Rename
- `Ctrl+Shift+C` Copy full path

Search syntax worth knowing: ext:pdf, dm:today, size:>100mb,
parent:C:\path (direct children only), regex:, and a space for AND, | for OR.

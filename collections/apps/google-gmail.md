# Gmail

Turn keyboard shortcuts on first: Settings › General › Keyboard shortcuts on.

## Go to
- `G I` Inbox
- `G S` Starred
- `G T` Sent
- `G D` Drafts
- `G A` All mail
- `/` Search
- `?` Show all shortcuts

## Conversations
- `J / K` Older / newer conversation
- `O` Open
- `U` Back to the list
- `X` Select
- `E` Archive
- `#` Delete
- `!` Report spam
- `B` Snooze
- `S` Star
- `Shift+I` Mark as read
- `Shift+U` Mark as unread
- `V` Move to
- `L` Label as

## Write
- `C` Compose
- `R` Reply
- `A` Reply all
- `F` Forward
- `Ctrl+Enter` Send

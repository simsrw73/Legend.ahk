# Outlook

New Outlook with the Outlook shortcut preset (Settings › General › Accessibility);
classic Outlook uses the same keys (match `ahk_exe OUTLOOK.EXE`).

## Mail
- `Ctrl+R` Reply
- `Ctrl+Shift+R` Reply all
- `Ctrl+F` Forward (not find)
- `Ctrl+Q` Mark as read
- `Ctrl+U` Mark as unread
- `Backspace` Archive
- `Ctrl+Shift+V` Move to folder
- `Insert` Flag
- `Ctrl+Enter` Send
- `Ctrl+.` Next message
- `Ctrl+,` Previous message

## Navigate
- `Ctrl+E` Search
- `Ctrl+Shift+I` Go to inbox
- `Ctrl+Y` Go to folder
- `Ctrl+1` Mail
- `Ctrl+2` Calendar
- `Ctrl+3` People
- `Ctrl+4` To Do

## Calendar
- `Ctrl+Shift+A` New event
- `Alt+↓ / ↑` Next / previous week
- `Ctrl+Alt+1–4` Day, work week, week, month view

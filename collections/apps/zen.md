# Zen

Zen's own keys; the rest are Firefox's (see the Firefox page).

## Zen
- `Ctrl+Alt+C` Toggle compact mode
- `Ctrl+Alt+S` Toggle floating sidebar
- `Ctrl+Alt+T` Toggle floating toolbar
- `Alt+B` Toggle sidebar width
- `Ctrl+Shift+C` Copy current URL
- `Ctrl+Alt+Shift+C` Copy current URL as Markdown
- `Ctrl+Alt+X` AI chatbot sidebar

## Workspaces
- `Ctrl+Alt+Q` Previous workspace
- `Ctrl+Alt+E` Next workspace

## Split view
- `Ctrl+Alt+V` Split vertically
- `Ctrl+Alt+H` Split horizontally
- `Ctrl+Alt+G` Split as a grid
- `Ctrl+Alt+U` Unsplit all

## Tabs
- `Ctrl+Shift+T` Reopen closed tab
- `Ctrl+1–8` Go to tab 1–8
- `Ctrl+L` Focus the address bar

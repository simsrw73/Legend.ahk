# Windows Terminal

## Tabs and panes
- `Ctrl+Shift+T` New tab
- `Ctrl+Shift+1–9` New tab with profile 1–9
- `Ctrl+Alt+1–9` Go to tab 1–9
- `Ctrl+Tab` Next tab
- `Alt+Shift+D` Split pane (auto)
- `Alt+Shift+Plus` Split right
- `Alt+Shift+-` Split down
- `Alt+←/↑/↓/→` Move between panes
- `Alt+Shift+←/↑/↓/→` Resize pane
- `Ctrl+Shift+W` Close pane

## Terminal
- `Ctrl+Shift+P` Command palette
- `Ctrl+Shift+F` Find
- `Ctrl+Shift+↑ / ↓` Scroll a line
- `Ctrl+Shift+PgUp / PgDn` Scroll a page
- `Ctrl+Shift+Home / End` Scroll to top / bottom
- `Alt+Enter` Full screen
- ``Win+` `` Quake window (from any app)
- `Ctrl+,` Settings

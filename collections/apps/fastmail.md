# Fastmail

## Go to
- `Shift+G M` Mail
- `Shift+G C` Calendar
- `Shift+G A` Contacts
- `Shift+G N` Notes
- `G` Go to folder
- `/` Search

## Mail
- `J / K` Next / previous
- `O` Open
- `U` Back to the mailbox
- `X` Select
- `Y` Archive
- `[` Archive and go to next
- `D` Delete
- `M` Move to folder
- `L` Labels
- `Shift+I` Mark as read
- `Shift+U` Mark as unread
- `Shift+M` Mute conversation

## Write
- `C` Compose
- `R` Reply
- `A` Reply all
- `F` Forward
- `Ctrl+Enter` Send
- `Ctrl+Shift+Enter` Schedule send

## Calendar
- `N` New event
- `D / W / M` Day / week / month
- `T` Today

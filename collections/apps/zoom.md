# Zoom

## Meeting
- `Alt+A` Mute / unmute
- `Space` Push to talk (hold, while muted)
- `Alt+V` Start / stop video
- `Alt+S` Share screen
- `Alt+T` Pause / resume share
- `Alt+Y` Raise / lower hand
- `Alt+H` Chat
- `Alt+U` Participants
- `Alt+F1 / F2` Speaker / gallery view
- `Alt+F` Full screen
- `Alt+R` Record locally
- `Alt+I` Invite
- `Alt+Q` Leave or end meeting

## Team chat
- `Ctrl+↑ / ↓` Previous / next chat
- `Ctrl+L` Focus the chat list
- `Ctrl+F` Search

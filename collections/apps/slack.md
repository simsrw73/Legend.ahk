# Slack

## Navigate
- `Ctrl+K` Jump to a conversation
- `Ctrl+G` Search
- `Alt+↑ / ↓` Previous / next conversation
- `Alt+Shift+↑ / ↓` Previous / next unread conversation
- `Ctrl+Shift+A` All unreads
- `Ctrl+Shift+T` Threads
- `Ctrl+Shift+M` Activity
- `Ctrl+Shift+K` Direct messages
- `Ctrl+[ / ]` Back / forward
- `Ctrl+Shift+D` Toggle sidebar
- `Ctrl+.` Toggle the right pane

## Messages
- `Esc` Mark the conversation read
- `Shift+Esc` Mark everything read
- `↑` Edit your last message
- `Ctrl+Shift+\` React to the last message
- `Ctrl+U` Upload a file
- `Ctrl+Shift+Enter` New snippet
- `Ctrl+Shift+Y` Set status

## Huddles
- `Ctrl+Shift+H` Start or leave a huddle
- `Ctrl+Shift+Space` Mute in a huddle
- `Ctrl+/` Show all shortcuts

# Notion

## Navigate
- `Ctrl+P` Search (or Ctrl+K)
- `Ctrl+[ / ]` Back / forward
- `Ctrl+Shift+U` Go up to the parent page
- `Ctrl+\` Toggle sidebar
- `Ctrl+Shift+L` Toggle dark mode
- `Ctrl+Shift+P` Move page to

## Blocks
- `/` Insert block menu
- `Esc` Select the current block
- `Ctrl+D` Duplicate block
- `Ctrl+/` Turn into or change a block
- `Ctrl+Shift+↑ / ↓` Move block up / down
- `Ctrl+Alt+T` Expand or collapse all toggles
- `Ctrl+Shift+M` Comment
- `Ctrl+Shift+H` Last used highlight color
- `Ctrl+Alt+0–9` Turn into text, heading, list, toggle…
- `Ctrl+E` Inline code
- `Ctrl+Shift+S` Strikethrough

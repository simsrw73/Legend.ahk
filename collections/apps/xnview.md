# XnView MP

## Browse and view
- `Enter` View the image
- `F11` Full screen
- `Esc` Back to the browser
- `PgDn / PgUp` Next / previous image
- `/` Fit to window
- `*` Original size

## Edit
- `Ctrl+U` Batch convert
- `F2` Rename
- `Ctrl+1–5` Rate 1–5 stars
- `Ctrl+0` Clear rating

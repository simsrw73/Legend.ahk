# Google Calendar

## Views
- `D` Day
- `W` Week
- `M` Month
- `X` Custom view
- `A` Schedule
- `T` Today
- `J / K` Next / previous period
- `G` Go to date

## Events
- `C` New event
- `E` Event details
- `Backspace` Delete event
- `/` Search
- `Q` Quick add
- `?` Show all shortcuts

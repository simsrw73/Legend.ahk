# superfile

Terminal file manager (spf). `?` shows every key.

## Move
- `J / K` Down / up
- `L / Enter` Open
- `H / Backspace` Parent folder
- `Tab / Shift+L` Next panel
- `N` New panel
- `Shift+N` Split panel
- `W` Close panel
- `Z` Zoxide jump
- `/` Search
- `.` Show dotfiles

## Files
- `Ctrl+N` New file or folder (end with \ for a folder)
- `Ctrl+R` Rename
- `Ctrl+C / Ctrl+X / Ctrl+V` Copy / cut / paste
- `Ctrl+D` Delete
- `Ctrl+P` Copy path
- `Ctrl+E` Extract archive
- `Ctrl+A` Compress
- `E` Open in editor
- `V` Selection mode
- `F` Toggle preview

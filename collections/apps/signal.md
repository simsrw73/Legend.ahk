# Signal

## Chats
- `Ctrl+N` New chat
- `Ctrl+F` Search
- `Alt+↑ / ↓` Previous / next chat
- `Alt+Shift+↑ / ↓` Previous / next unread chat
- `Ctrl+1–9` Jump to chat 1–9
- `Ctrl+Shift+F` Search in the chat
- `Ctrl+Shift+A` Archive chat
- `Ctrl+Shift+M` All media in the chat

## Messages
- `Ctrl+Shift+R` Reply to the selected message
- `Ctrl+Shift+E` React to the selected message
- `Ctrl+Shift+S` Forward the selected message
- `↑` Edit your last message
- `Ctrl+U` Attach a file
- `Ctrl+Shift+J` Emoji picker

## Calls
In a call:
- `Shift+M` Toggle mute
- `Shift+V` Toggle video
- `Ctrl+/` Show all shortcuts

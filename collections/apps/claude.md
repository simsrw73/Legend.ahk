# Claude

## Chat
- `Ctrl+N` New chat
- `Ctrl+K` Search chats
- `Ctrl+Shift+I` Incognito chat
- `Ctrl+U` Upload a file
- `Ctrl+Shift+E` Toggle extended thinking
- `Esc` Stop the response
- `Ctrl+.` Toggle sidebar
- `Ctrl+Shift+,` Settings
- `Ctrl+/` Show all shortcuts

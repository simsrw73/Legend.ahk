# Microsoft Edge

## Tabs
- `Ctrl+Shift+T` Reopen closed tab
- `Ctrl+Shift+A` Search tabs
- `Ctrl+Shift+,` Toggle vertical tabs
- `Ctrl+1–8` Go to tab 1–8
- `Ctrl+9` Go to the last tab
- `Ctrl+Shift+N` New InPrivate window

## Edge features
- `Ctrl+Shift+.` Copilot
- `Ctrl+Shift+/` Toggle sidebar
- `Ctrl+Shift+Y` Collections
- `Ctrl+Shift+S` Web capture
- `F9` Immersive reader
- `Ctrl+Shift+U` Read aloud
- `Ctrl+Shift+M` Switch profile

## Browser
- `Ctrl+L` Focus the address bar
- `Ctrl+H` History
- `Ctrl+J` Downloads
- `Ctrl+Shift+O` Favorites
- `Ctrl+Shift+Delete` Clear browsing data
- `Shift+Esc` Browser task manager
- `F12` Developer tools

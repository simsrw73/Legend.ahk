# Spotify

## Play
- `Ctrl+→ / ←` Next / previous track
- `Shift+→ / ←` Seek forward / back
- `Ctrl+↑ / ↓` Volume up / down
- `Ctrl+S` Shuffle
- `Ctrl+R` Repeat
- `Alt+Shift+B` Like

## Go to
- `Ctrl+K` Quick search
- `Ctrl+L` Search
- `Alt+Shift+H` Home
- `Alt+Shift+J` Now playing
- `Alt+Shift+Q` Queue
- `Alt+Shift+S` Liked songs
- `Alt+Shift+0` Your library
- `Alt+Shift+1` Your playlists
- `Alt+←/→` Back / forward

## Layout
- `Alt+Shift+L` Toggle library sidebar
- `Alt+Shift+R` Toggle now-playing sidebar
- `Alt+J` Context menu
- `Ctrl+/` Show all shortcuts

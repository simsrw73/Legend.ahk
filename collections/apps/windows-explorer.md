# File Explorer

## Navigate
- `Alt+D` Address bar (Ctrl+L also)
- `Ctrl+E` Search
- `Alt+↑` Up one folder
- `Alt+← / →` Back / forward
- `Ctrl+Shift+N` New folder
- `Alt+P` Preview pane
- `Alt+Shift+P` Details pane
- `Ctrl+Shift+1–8` View: extra large icons … content

## Tabs
- `Ctrl+T` New tab
- `Ctrl+W` Close tab
- `Ctrl+Tab` Next tab

## Files
- `F2` Rename
- `Ctrl+Shift+C` Copy as path
- `Alt+Enter` Properties
- `Shift+F10` Classic context menu
- `Shift+Delete` Delete permanently

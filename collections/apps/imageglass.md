# ImageGlass

## View
- `→ / ←` Next / previous image
- `Home / End` First / last image
- `F` Go to image
- `F9` Fit window to image
- `F10` Frameless
- `F11` Full screen
- `F12` Slideshow
- `Alt+←/↑/↓/→` Pan

## Image
- `Ctrl+.` Rotate left
- `Ctrl+/` Rotate right
- `Ctrl+;` Flip horizontally
- `Ctrl+'` Flip vertically
- `E` Edit in the external editor
- `D` Open with
- `Ctrl+Shift+R` Reload the image list
- `Ctrl+,` Settings

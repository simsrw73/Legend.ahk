# Spark

Spark Desktop's own preset (Settings › Shortcuts also offers Gmail and Superhuman presets).

## Mail
- `Ctrl+K` Command center
- `E` Mark as done
- `S` Snooze
- `D` Pin
- `G` Set aside
- `I` Mark as priority
- `L` Add or remove a label
- `U` Mark as read
- `Ctrl+Alt+U` Mark all as read
- `Shift+1` Mark as spam
- `→ / ←` Next / previous email

## Write
- `R` Reply all
- `Shift+R` Reply
- `F` Forward
- `Ctrl+Enter` Send

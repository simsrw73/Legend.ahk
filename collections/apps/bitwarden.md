# Bitwarden

## Desktop app
- `Ctrl+U` Copy username
- `Ctrl+P` Copy password
- `Ctrl+T` Copy TOTP code
- `Ctrl+G` Password generator
- `Ctrl+L` Lock vault
- `Ctrl+Shift+M` Hide to tray
- `Ctrl+Shift+T` Keep on top

## Browser extension
- `Ctrl+Shift+L` Autofill login (again to cycle matches)
- `Ctrl+Shift+Y` Open the extension
- `Ctrl+Shift+9` Generate and copy a password

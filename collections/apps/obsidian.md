# Obsidian

## Find
- `Ctrl+O` Quick switcher (open or create a note)
- `Ctrl+P` Command palette
- `Ctrl+Shift+F` Search all notes
- `Ctrl+Alt+← / →` Back / forward

## Notes
- `Ctrl+E` Toggle reading view
- `Ctrl+K` Insert link
- `Ctrl+L` Toggle checkbox
- `Ctrl+;` Add property
- `Alt+Enter` Follow link under cursor
- `F2` Rename note

## Tabs
- `Ctrl+Tab` Next tab
- `Ctrl+Shift+T` Reopen closed tab
- `Ctrl+1–8` Go to tab 1–8
- `Ctrl+,` Settings (Hotkeys lists and changes all keys)

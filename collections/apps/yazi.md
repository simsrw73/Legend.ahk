# Yazi

Terminal file manager. `F1` or `~` shows every key.

## Move
- `H / J / K / L` Parent / down / up / open
- `G G / Shift+G` Top / bottom
- `Z` Jump with fzf
- `Shift+Z` Jump with zoxide
- `F` Filter
- `S` Search by name (fd)
- `Shift+S` Search by content (ripgrep)
- `/ / ?` Find next / previous
- `.` Show hidden files

## Files
- `Space` Select
- `V` Visual select
- `Y / X / P` Copy / cut / paste
- `D` Trash
- `Shift+D` Delete permanently
- `A` Create (end with / for a folder)
- `R` Rename
- `O / Shift+O` Open / open with
- `C C` Copy path
- `C F` Copy file name
- `;` Run a shell command

## Tabs
- `T T` New tab
- `1–9` Switch tab
- `[ / ]` Previous / next tab

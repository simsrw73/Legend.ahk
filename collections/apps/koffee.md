# Koffee

Vim-style file explorer. `?` opens Settings with every command and key.

## Move
- `J / K` Down / up
- `H` Parent folder
- `L` Open
- `Shift+H / Shift+L` Back / forward
- `G G` First item
- `Shift+G` Last item
- `Ctrl+J / Ctrl+K` Half page down / up
- `F` Find by name (`;` next match)
- `/` Search (Ctrl+S includes subfolders)
- `M` Set a bookmark
- `'` Go to a bookmark
- `G R` Drives
- `Tab` Path box

## Files
- `Space` Select
- `O / Shift+O` New file / folder
- `C` Rename
- `D` Move (then P to put)
- `Y` Copy (then P to put)
- `Delete` Recycle
- `U / Shift+U` Undo / redo
- `Ctrl+Shift+C` Copy paths
- `Ctrl+Shift+T` Terminal here
- `Ctrl+Shift+E` Explorer here
- `F9` Show hidden files

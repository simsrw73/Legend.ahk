# Zed

## Find anything
- `Ctrl+Shift+P` Command palette
- `Ctrl+P` Go to file
- `Ctrl+Shift+O` Go to symbol in file
- `Ctrl+T` Go to symbol in project
- `Ctrl+G` Go to line
- `Ctrl+Shift+F` Search in project
- `Ctrl+K Ctrl+S` Keymap editor

## AI
- `Ctrl+?` Agent panel
- `Ctrl+Enter` Inline assist
- `Tab` Accept edit prediction

## Code
- `F12` Go to definition
- `Shift+F12` Find references
- `F2` Rename symbol
- `Ctrl+.` Code actions
- `Ctrl+D` Add next match
- `Ctrl+Shift+L` Select all matches

## Layout
- `Ctrl+B` Toggle left dock
- `Ctrl+J` Toggle bottom dock
- ``Ctrl+` `` Toggle terminal
- `Ctrl+Shift+E` Project panel
- `Ctrl+Shift+G` Git panel
- `Ctrl+K Z` Zen mode

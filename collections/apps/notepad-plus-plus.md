# Notepad++

## Edit
- `Ctrl+D` Duplicate line
- `Ctrl+L` Delete line
- `Ctrl+Shift+↑ / ↓` Move line up / down
- `Ctrl+J` Join lines
- `Ctrl+Q` Toggle comment
- `Ctrl+U / Ctrl+Shift+U` Lowercase / uppercase
- `Alt+Shift+←/↑/↓/→` Column select
- `Alt+C` Column editor

## Find
- `Ctrl+Shift+F` Find in files
- `F3 / Shift+F3` Find next / previous
- `Ctrl+F3` Find the selected text
- `Ctrl+B` Go to matching brace
- `Ctrl+F2` Toggle bookmark
- `F2` Next bookmark

## View
- `Ctrl+Tab` Next document
- `Ctrl+Shift+T` Reopen closed tab
- `Alt+0` Fold all
- `Alt+Shift+0` Unfold all
- `F11` Full screen
- `Ctrl+Shift+R` Start / stop macro recording
- `Ctrl+Shift+P` Play macro

# Cursor

The AI keys; the editor keys are VS Code's (see the Visual Studio Code page).

## AI
- `Ctrl+I` Agent
- `Ctrl+L` Chat (adds the selection)
- `Ctrl+K` Inline edit of the selection
- `Ctrl+Shift+L` Add the selection to the chat
- `Ctrl+.` Switch agent mode
- `Ctrl+/` Switch model
- `Ctrl+Enter` Accept all changes
- `Ctrl+Backspace` Reject all changes
- `Tab` Accept the suggestion
- `Ctrl+→` Accept the next word of the suggestion

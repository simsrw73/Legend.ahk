# Firefox

## Tabs
- `Ctrl+Shift+T` Reopen closed tab
- `Ctrl+Shift+N` Reopen closed window
- `Ctrl+1–8` Go to tab 1–8
- `Ctrl+9` Go to the last tab
- `Ctrl+Shift+PgUp / PgDn` Move tab left / right
- `Ctrl+M` Mute tab
- `Ctrl+Shift+P` New private window

## Page
- `Ctrl+L` Focus the address bar (type % to search tabs, * bookmarks, ^ history)
- `/` Quick find
- `'` Quick find in links only
- `F9` Reader view
- `Ctrl+Shift+S` Screenshot
- `Ctrl+Shift+]` Picture-in-picture

## Browser
- `Ctrl+B` Bookmarks sidebar
- `Ctrl+H` History sidebar
- `Ctrl+Shift+O` Library
- `Ctrl+J` Downloads
- `Ctrl+Shift+A` Add-ons and themes
- `Ctrl+Shift+Delete` Clear recent history
- `F12` Developer tools

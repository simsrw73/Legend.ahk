# Thunderbird

## Mail
- `Ctrl+M` New message
- `Ctrl+R` Reply
- `Ctrl+Shift+R` Reply all
- `Ctrl+L` Forward
- `A` Archive
- `J` Mark as junk
- `M` Toggle read
- `S` Toggle star
- `1–9` Tag
- `Ctrl+Shift+K` Quick filter
- `Ctrl+K` Search all messages
- `Ctrl+Enter` Send

## Move around
- `F` Next message
- `B` Previous message
- `N` Next unread message
- `T` Next unread thread
- `G` Next unread folder
- `F8` Toggle message pane
- `Ctrl+Shift+B` Address book

## Spaces
- `Ctrl+1` Mail
- `Ctrl+2` Address book
- `Ctrl+3` Calendar
- `Ctrl+4` Tasks
- `Ctrl+5` Chat

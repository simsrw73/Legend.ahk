# Google Chrome

## Tabs
- `Ctrl+Shift+T` Reopen closed tab
- `Ctrl+Shift+A` Search tabs
- `Ctrl+1–8` Go to tab 1–8
- `Ctrl+9` Go to the last tab
- `Ctrl+Shift+PgUp / PgDn` Move tab left / right
- `Ctrl+Shift+N` New incognito window

## Address bar
- `Ctrl+L` Focus the address bar
- `Ctrl+K` Search from the address bar
- `Alt+Enter` Open what you typed in a new tab
- `Ctrl+D` Bookmark page

## Browser
- `Ctrl+H` History
- `Ctrl+J` Downloads
- `Ctrl+Shift+O` Bookmarks manager
- `Ctrl+Shift+B` Toggle bookmarks bar
- `Ctrl+Shift+M` Switch profile
- `Ctrl+Shift+Delete` Clear browsing data
- `Shift+Esc` Chrome Task Manager
- `F12` Developer tools
- `Ctrl+U` View source

# Fantastical

## Calendar
- `Ctrl+Alt+Space` Mini window (from any app)
- `Ctrl+N` New event (type it in plain language)
- `Ctrl+K` Switch between event and task while adding
- `Ctrl+T` Go to today
- `Ctrl+Shift+T` Go to date
- `Ctrl+←` Previous day / week / month
- `Ctrl+→` Next day / week / month
- `Ctrl+E` Show details
- `Ctrl+R` Show or hide tasks
- `Ctrl+Alt+S` Show sidebar

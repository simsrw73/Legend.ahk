# Discord

Same keys in Dorion (match `ahk_exe Dorion.exe`).

## Navigate
- `Ctrl+K` Quick switcher
- `Alt+↑ / ↓` Previous / next channel
- `Alt+Shift+↑ / ↓` Previous / next unread channel
- `Ctrl+Alt+↑ / ↓` Previous / next server
- `Ctrl+Alt+→` Toggle last server and DMs
- `Shift+PgUp` Jump to the oldest unread message
- `Ctrl+I` Inbox
- `Ctrl+P` Pinned messages
- `Ctrl+U` Member list

## Read and write
- `Esc` Mark channel read
- `Shift+Esc` Mark server read
- `↑` Edit your last message
- `Ctrl+E` Emoji picker
- `Ctrl+G` GIF picker
- `Ctrl+Shift+U` Upload a file

## Voice
- `Ctrl+Shift+M` Toggle mute
- `Ctrl+Shift+D` Toggle deafen
- `Ctrl+Enter` Answer incoming call
- `Ctrl+/` Show all shortcuts

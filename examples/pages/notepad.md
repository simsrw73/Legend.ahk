# Notepad

Notepad's own shortcuts. Ctrl+Alt+D is added by 02-page-files.ahk, so it shows as bound.

## Editing
### File
- `Ctrl+N` New tab
- `Ctrl+S` Save
- `Ctrl+Shift+S` Save as

### Text
- `Ctrl+F` Find
- `Ctrl+H` Replace
- `Ctrl+G` Go to line
- `F5` Insert time & date
- `Ctrl+Alt+D` Insert today's date

## View
- `Ctrl+Plus` Zoom in
- `Ctrl+Minus` Zoom out
- `Ctrl+0` Reset zoom

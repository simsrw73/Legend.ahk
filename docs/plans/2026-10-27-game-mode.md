# Game mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An opt-in `GameMode` option to `Legend.Start` that suspends the whole host script while a game has focus, with a Suspend-exempt toggle key.

**Architecture:** One new module, `src/GameMode.ahk`, in three layers: `LegendGameRules` (pure classifier over a process description), `LegendGameMode` (state machine over an injectable `System` seam: describe a window, suspend, close sessions), and `LegendGameSystem` (the real Win32 side: Toolhelp snapshot, process times, DWM bounds, WinEvent hooks, `Suspend`). `Legend.Start` builds it only when `GameMode` is set.

**Tech Stack:** AutoHotkey v2, Win32 via `DllCall` (kernel32 Toolhelp/`GetProcessTimes`, user32 `SetWinEventHook`/`GetMonitorInfo`, dwmapi).

**Spec:** `docs/specs/2026-10-27-game-mode-design.md`

## Global Constraints

- Off unless `GameMode` is set; `GameMode` absent, `""` or `false` installs no hook and no hotkey.
- When on, a game in front suspends the **whole script** (`Suspend(true)`).
- `ToggleKey` default `"^!g"`; `""` registers none; registered with `Hotkey(key, fn, "S")`.
- `Folders`/`Launchers` add to built-ins; `Games`/`NotGames` have no built-ins.
- Exe names compare case-insensitively; folder entries are case-insensitive substrings of the full path.
- Every function declares its locals with a `local` line; no local shadows a built-in (`log`, `menu`, `min`, `max`, `mod`, `hotkey`, `file`). `Check-Locals.ps1` and the all-names host enforce this.
- Use `==` only where case matters; exe/path matching uses `StrLower` or `InStr(..., , false)`.
- Run AutoHotkey only from PowerShell. Don't send keys or click on the user's screen.
- Full suite: `pwsh -NoProfile -File tests/Run-Tests.ps1`, all green before each commit.
- Commits are GPG-signed; never bypass. Batch commits at the end if the agent cache may expire.

## Review Focus

1. **The same window reported foreground again** (focus flicker, a game re-activating itself) must not clear a manual override or re-run detection. → Task 2 test `GameMode: a repeated foreground event keeps a manual override`.
2. **A process that exits or can't be read** (Describe returns `""`) is treated as not a game and raises nothing. → Task 2 test `GameMode: an unreadable window counts as not a game`.
3. **Host already suspended** when a game gains and then loses focus: stays suspended. → Task 2 test `GameMode: a suspension Legend didn't cause survives leaving a game`.
4. **Legend's own windows** becoming foreground (overlay, picker) must not resume or suspend. → Task 2 test `GameMode: Legend's own windows are ignored`.
5. **Malformed option values** (`Games: "x.exe"` as a string, `Fullscreen: "yes"`, an unknown property) warn and fall back, never throw. → Task 1 test `GameMode config: bad values warn and fall back`.

### Task 2: State machine

**Files:**
- Modify: `src/GameMode.ahk`
- Modify: `tests/GameMode.Tests.ahk`

**Interfaces:**
- Consumes: `LegendGameRules(config).IsGame(proc)`.
- Produces:
  - `LegendGameMode(rules, system)`. `system` has `Describe(hwnd) → proc | "" | "own"` (`"own"` = a window of this script's process), `IsSuspended() → bool`, `Suspend(on)`, `CloseSessions()`.
  - `.OnForeground(hwnd)`, `.OnLocationChange(hwnd)`, `.Toggle(hwnd)` (`hwnd` = the current foreground window, passed in by the caller).
  - Properties for tests: `.Owned` (Legend caused the current suspension), `.Current` (last foreground hwnd), `.Manual` (hwnd under manual override, or 0).

- [ ] **Step 1: Write failing tests** with a fake system `GameSys_New(procs)` where `procs` is a Map hwnd → proc/""/"own", recording `Suspended` (bool), `Log` (Array of `"suspend"`, `"resume"`, `"close"`). Rules from `LegendGameRules(LegendGameMode.Config(true, Noop))`; hwnd 1 = `Proc("game.exe", "", ["steam.exe"])`, 2 = `Proc("notepad.exe")`, 3 = `""`, 4 = `"own"`, 5 = `Proc("indie.exe", "", [], false)` whose `.Fullscreen` the test flips.
  - `GameMode: focusing a game closes sessions then suspends` — `OnForeground(1)` → `Log == ["close", "suspend"]`, `Owned`.
  - `GameMode: leaving a game resumes` — `OnForeground(1)`, `OnForeground(2)` → not suspended, `Log[-1] == "resume"`, `!Owned`.
  - `GameMode: a suspension Legend didn't cause survives leaving a game` — fake starts suspended; `OnForeground(1)`, `OnForeground(2)` → still suspended, `Log.Length == 0`.
  - `GameMode: an unreadable window counts as not a game` — `OnForeground(1)`, `OnForeground(3)` → resumed, no error.
  - `GameMode: Legend's own windows are ignored` — `OnForeground(1)`, `OnForeground(4)` → still suspended, `Current == 1`.
  - `GameMode: toggle flips immediately` — `OnForeground(2)`, `Toggle(2)` → suspended, `Owned`, `Manual == 2`; `Toggle(2)` → resumed, `!Owned`.
  - `GameMode: toggle resumes a suspension Legend didn't cause` — fake starts suspended, `Current := 2`, `Toggle(2)` → resumed.
  - `GameMode: a repeated foreground event keeps a manual override` — `OnForeground(1)`, `Toggle(1)` (resumed), `OnForeground(1)` → still resumed, `Manual == 1`.
  - `GameMode: a different window clears the override` — continue from above: `OnForeground(2)`, `OnForeground(1)` → suspended, `Manual == 0`.
  - `GameMode: going fullscreen in place suspends` — `OnForeground(5)` (not suspended), set `procs[5].Fullscreen := true`, `OnLocationChange(5)` → suspended, `Owned`.
  - `GameMode: the location check never resumes or overrides` — suspended on 5 via fullscreen, flip `Fullscreen := false`, `OnLocationChange(5)` → still suspended; after `Toggle(5)` (resumed) and `Fullscreen := true`, `OnLocationChange(5)` → still resumed. `OnLocationChange(2)` while `Current == 5` does nothing.

- [ ] **Step 2: Run** the suite. Expected: new tests fail.

- [ ] **Step 3: Implement** the methods. Semantics:
  - `OnForeground(hwnd)`: `"own"` → return. `hwnd == Manual` → return. Otherwise `Manual := 0`, `Current := hwnd`, then `Apply(IsGame)`. `Apply(true)`: if not suspended → `CloseSessions()`, `Suspend(true)`, `Owned := true`. `Apply(false)`: if `Owned` → `Suspend(false)`, `Owned := false`.
  - `OnLocationChange(hwnd)`: only when `hwnd == Current`, `Manual != hwnd`, not suspended, and the proc is a game → suspend as in `Apply(true)`.
  - `Toggle(hwnd)`: if suspended → `Suspend(false)`, `Owned := false`; else `CloseSessions()`, `Suspend(true)`, `Owned := true`. Then `Manual := hwnd`, `Current := hwnd` (unless `"own"`).
  - `""` from Describe means not a game.

- [ ] **Step 3: Implement** `LegendGameSystem`:
  - `Describe(hwnd)`: `0` or vanished → `""`; `WinGetPID` equals `GetCurrentProcessId` → `"own"`; class `Progman`/`WorkerW`/`Shell_TrayWnd` → `""`; otherwise `Process(pid)` merged with `Fullscreen: IsFullscreen(hwnd)` into a fresh object (don't mutate the cache). Wrap reads in `try`; failure → `""`.
  - `Process(pid)`: one `CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS=2)` walk building pid → `{Parent, Exe}` (`PROCESSENTRY32W`, size 568 on x64: pid at 8, parent at 32, `szExeFile` at 44). Path via `OpenProcess(0x1000)` + `QueryFullProcessImageNameW` (`""` if denied). Creation time via `GetProcessTimes`. Ancestors: walk parents up to 16 deep; stop at a pid missing from the snapshot, or whose creation time is later than its child's; if a parent's time can't be read, include its exe and keep going.
  - `IsFullscreen(hwnd)`: inside `LegendWindows.InPhysicalPixels`, `(WinGetStyle & 0xC00000) != 0xC00000` and `LegendWindows.Bounds(hwnd)` equals the `rcMonitor` from `MonitorFromWindow(hwnd, 2)` + `GetMonitorInfoW`.
  - `IsSuspended() => A_IsSuspended`, `Suspend(on) => Suspend(on)`, `CloseSessions` calls the callback passed to `Install`.
  - Hooks in `Install`: `SetWinEventHook(3, 3, 0, cb, 0, 0, 0)` (`EVENT_SYSTEM_FOREGROUND`, out of context) calling `OnForeground(hwnd)`. On each foreground change, unhook the previous location hook and install `SetWinEventHook(0x800B, 0x800B, 0, cb, pid, 0, 0)` scoped to that window's pid, whose callback forwards only `idObject == 0 && idChild == 0` to `OnLocationChange(hwnd)`. Keep the `CallbackCreate` pointers alive on the instance.
  - `Legend.Start`: after page loading, `config := LegendGameMode.Config(this.Options.GameMode, (message) => this.Registry.Warn(message))`; if `config` → `this.GameMode := LegendGameMode.Install(config, () => Legend.Close())`. Leave `HotIf()` reset afterwards.
